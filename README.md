# 📚 FastAPI Bookstore API

A robust and secure RESTful API built with **FastAPI** and **SQLModel**, designed for managing bookstores, users, authentication, and order processing.

## 🚀 Features
- **FastAPI & SQLModel**: Modern, high-performance async-ready framework with elegant ORM support.
- **Authentication & Authorization**: Secure JWT-based authentication with role-based access control (Admin, Staff, Customer).
- **Data Validation**: Strict payload validation using Pydantic DTOs.
- **Database Management**: Supports PostgreSQL for production and SQLite for testing environments.

## 🛠️ Tech Stack
- Python 3.10+
- FastAPI
- SQLModel / SQLAlchemy
- Pydantic
- Pytest (for automated testing)
