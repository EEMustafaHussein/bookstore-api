# ✨ ملابس الأحلام — متجر ملابس نسائية

متجر إلكتروني كامل لبيع الملابس النسائية الجديدة وملابس **البالة**، بتصميم عربي (من اليمين لليسار) عصري مليء بالحركات، ولوحة تحكم لإدارة كل شيء.

مبني بـ **Python + FastAPI + SQLModel** (نفس الأدوات المستخدمة في مشروع bookstore-api)، وواجهة HTML/CSS/JavaScript بدون أي مكتبات خارجية ثقيلة.

---

## 🌸 ماذا يحتوي المتجر؟

### للزبائن
- صفحة رئيسية بسماء ليلية متحركة، عنوان يظهر كلمةً كلمة، أقواس صور عائمة، وشريط أقسام متحرك.
- **ركن البالة** بتصميم مختلف (ورق كرافت وصور بولارويد مائلة وختم دوّار) — كل قطعة فريدة.
- تصفح حسب القسم، بحث، ترتيب حسب السعر، وتقسيم صفحات.
- صفحة منتج بمعرض صور (سحب على الجوال، تكبير عند المرور بالماوس)، اختيار المقاس واللون والكمية.
- **سلة جانبية** تُفتح بحركة ناعمة، والقطعة "تطير" إلى السلة عند إضافتها.
- تسجيل بالبريد الإلكتروني وكلمة المرور، وحفظ السلة عند تسجيل الدخول.
- إتمام الطلب: الاسم، الهاتف (رقم عراقي)، المحافظة، العنوان، وطريقة الدفع.
- **الدفع عند الاستلام** أو **بالبطاقة (ماستر كارد / فيزا / Apple Pay / Google Pay)** عبر Stripe.
- صفحة «طلباتي» مع شريط حالة الطلب، وإمكانية إلغاء الطلب قبل تأكيده.
- صفحة **«من أنا»** للمصمم: الصورة، النبذة، المهارات، المواقع، رقم الهاتف وزر واتساب.
- روابط مواقع التواصل (إنستغرام، فيسبوك، تيك توك، سناب، تيليغرام، واتساب، يوتيوب، إكس).

### الصلاحيات

| الإجراء | المالك (أنت) | المسؤول | الزبونة |
|---|:-:|:-:|:-:|
| نشر/تعديل/حذف المنتجات والصور والأسعار | ✅ | ✅ | ❌ |
| إضافة/حذف الأقسام | ✅ | ✅ | ❌ |
| إدارة الطلبات وتغيير حالتها | ✅ | ✅ | ❌ |
| **إضافة المسؤولين وإزالتهم** | ✅ | ❌ | ❌ |
| إيقاف الحسابات وتعيين كلمة مرور جديدة | ✅ | ❌ | ❌ |
| إعدادات المتجر وروابط التواصل وصفحة «من أنا» | ✅ | ❌ | ❌ |
| الشراء | ✅ | ✅ | ✅ |

حساب المالك محمي: لا يمكن إيقافه أو إزالة صلاحياته من لوحة التحكم.

### الأمان
- كلمات المرور مشفّرة بخوارزمية Argon2.
- حماية من CSRF في كل النماذج، وحد لمحاولات تسجيل الدخول الخاطئة.
- كل صورة تُفحص وتُعاد معالجتها وتُحفظ بصيغة WebP (لا يمكن رفع ملف ضار على أنه صورة).
- رؤوس أمان (Content-Security-Policy وغيرها)، وروابط التواصل تُقبل فقط بصيغة http/https.
- المخزون يُحجز بشكل ذرّي: لا يمكن بيع آخر قطعة لشخصين في نفس اللحظة.
- طلبات البطاقة غير المدفوعة تُلغى بعد ساعة وتعود قطعها للمخزون تلقائياً.
- بيانات البطاقة لا تمر على خادمك أبداً (الدفع على صفحة Stripe الآمنة).

## 🚀 التشغيل على جهازك

> تحتاج Python 3.10 أو أحدث.

### على Windows (PowerShell)
```powershell
cd dreams-store
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

### على Linux / macOS
```bash
cd dreams-store
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

### ثم
1. افتح ملف `.env` وغيّر `SECRET_KEY` إلى نص عشوائي طويل:
   ```bash
   python -c "import secrets; print(secrets.token_urlsafe(48))"
   ```
2. أنشئ حساب المالك (سيسألك عن البريد وكلمة المرور):
   ```bash
   python create_owner.py
   ```
   أو ضع `OWNER_EMAIL` و `OWNER_PASSWORD` في `.env` وسيُنشأ تلقائياً عند أول تشغيل.
3. (اختياري) أضف منتجات تجريبية برسومات جاهزة لترى شكل المتجر:
   ```bash
   python seed_demo.py
   ```
4. شغّل المتجر:
   ```bash
   uvicorn app.main:app --reload
   ```
5. افتح المتصفح على **http://127.0.0.1:8000**، وسجّل الدخول بحساب المالك ثم ادخل **/admin**.

### أول خطوات في لوحة التحكم
1. **إعدادات المتجر**: اسم المتجر، شريط الإعلان، أجور التوصيل، وروابط مواقع التواصل.
2. **صفحة «من أنا»**: اسمك، صورتك، نبذتك، رقم هاتفك ومواقعك.
3. **الأقسام**: أضف أقساماً مثل فساتين، عبايات، بلايز...
4. **نشر منتج جديد**: الصور (اسحبها وأفلتها)، السعر، الوصف، المقاسات والألوان، واختر «جديد» أو «بالة».
5. **المسؤولون والحسابات**: أضف مسؤولاً ببريد وكلمة مرور — يستطيع النشر والحذف لكن لا يستطيع إضافة أو حذف مسؤولين.

## 💳 تفعيل الدفع بالبطاقة (ماستر كارد وفيزا)

الدفع يتم عبر **Stripe Checkout**: الزبونة تنتقل لصفحة دفع آمنة، ثم تعود للمتجر وطلبها مدفوع.

1. أنشئ حساباً على [stripe.com](https://stripe.com) وخذ المفتاح السري (`sk_live_...` أو `sk_test_...` للتجربة).
2. في `.env`:
   ```
   STRIPE_SECRET_KEY=sk_test_...
   STRIPE_CURRENCY=usd
   STRIPE_EXCHANGE_RATE=1310
   BASE_URL=https://your-domain.com
   PAYMENT_DEMO_MODE=false
   ```
   الأسعار في المتجر بالدينار، ويُحوَّل المبلغ لعملة Stripe حسب `STRIPE_EXCHANGE_RATE` (كم دينار = 1 دولار).
3. في لوحة Stripe ← Developers ← Webhooks أضف الرابط:
   `https://your-domain.com/checkout/stripe/webhook`
   مع الأحداث: `checkout.session.completed`, `checkout.session.async_payment_succeeded`, `checkout.session.expired`
   ثم ضع مفتاح التوقيع في `STRIPE_WEBHOOK_SECRET=whsec_...`

> ⚠️ **ملاحظة مهمة:** Stripe يتطلب حساباً تجارياً في دولة مدعومة، والعراق ليس منها حالياً.
> إذا لم يتوفر لك حساب، يبقى **الدفع عند الاستلام** يعمل بشكل كامل، ويمكن لاحقاً إضافة بوابة دفع عراقية
> (مثل ZainCash أو FIB أو Qi Card) كملف جديد داخل `app/payments/` على نفس طريقة `stripe.py`.

**الوضع التجريبي:** `PAYMENT_DEMO_MODE=true` يعرض صفحة دفع تجريبية لتجربة المتجر على جهازك دون أي أموال حقيقية.
لا تفعّله أبداً على الموقع الحقيقي (يظهر شريط تنبيه أعلى الموقع عندما يكون مفعّلاً).

## 🌍 النشر على الإنترنت (حتى الناس تلكى المتجر)

### الطريقة الأسهل: Render
الملف `render.yaml` (في جذر المستودع) جاهز، ويجهّز كل شيء تلقائياً: الخادم، قرص دائم للصور وقاعدة البيانات، HTTPS، ومفتاح سري عشوائي.

1. ارفع المشروع على GitHub.
2. سجّل في [render.com](https://render.com) بحساب GitHub.
3. اختر **New → Blueprint** ثم اختر مستودع `bookstore-api`.
4. سيطلب منك ثلاث قيم: `OWNER_EMAIL` و `OWNER_PASSWORD` و `OWNER_NAME` — هذا حساب المالك (أنت).
5. اضغط **Apply**. بعد دقائق يصير الموقع على رابط مثل `https://dreams-store.onrender.com`.

> 💰 الخطة المطلوبة **Starter** (حوالي 7$ شهرياً + 0.25$ لكل GB تخزين)، لأن الخطة المجانية في Render
> لا تدعم القرص الدائم — يعني الصور والطلبات تنمسح عند كل إعادة تشغيل. تأكد من السعر الحالي في صفحة أسعار Render.

**دومين خاص (اختياري):** اشترِ دومين مثل `ahlam-dresses.com`، أضفه من إعدادات الخدمة في Render ← Custom Domains،
ثم أضف متغير البيئة `BASE_URL=https://ahlam-dresses.com`.

### حتى يظهر المتجر في بحث Google
1. افتح [Google Search Console](https://search.google.com/search-console) وأضف رابط موقعك (اختر **URL prefix**).
2. اختر طريقة التحقق **HTML tag** وانسخ الوسم.
3. في لوحة التحكم ← **إعدادات المتجر** ← «الظهور في بحث Google» الصق الوسم واحفظ، ثم اضغط **Verify** في Google.
4. من **Sitemaps** أرسل: `sitemap.xml`
5. انشر رابط المتجر على صفحاتك في مواقع التواصل — هذا يسرّع ظهوره.

المتجر يرسل لـ Google خريطة بكل المنتجات والأقسام، وبيانات كل منتج (السعر، التوفر، جديد أو مستعمل) بالصيغة التي يفهمها Google.
ظهور الموقع في نتائج البحث يأخذ عادة من أيام إلى أسابيع.

### طرق أخرى
- **Docker** على أي سيرفر (مثل VPS):
  ```bash
  docker compose up -d --build
  ```
  (البيانات والصور تُحفظ في volumes دائمة. شغّله خلف HTTPS واجعل `COOKIE_SECURE=true`.)
- لاستخدام PostgreSQL بدلاً من SQLite: `pip install "psycopg[binary]"` ثم
  `DATABASE_URL=postgresql+psycopg://user:password@host:5432/dreams`
