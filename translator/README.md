# ترجمان: مترجم صوتي بالسماعات

نموذج أولي يشتغل من متصفح Chrome على تلفون Android. يسمع المحادثة من مايك التلفون، ويعرف اللغة تلقائياً، ويترجم بصوت:

- **التكة اليسرى (L) بإذنك:** تسمع ترجمة كلام الشخص المقابل بالعربي.
- **التكة اليمنى (R) بإذن الشخص المقابل:** يسمع ترجمة كلامك بلغته (كردي سوراني أو تركي أو إنكليزي).

```
مايك التلفون ← كشف بداية ونهاية الجملة ← ElevenLabs (كلام لنص + كشف اللغة)
            ← Claude (يتأكد من اللغة ويترجم) ← ElevenLabs (نص لكلام)
            ← التكة اليسرى أو اليمنى حسب منو حجى
```

## ليش مايك التلفون مو مايك السماعة؟

أول ما يشتغل مايك سماعة البلوتوث، السماعة تتحول لوضع المكالمة (HFP): صوت مونو وجودة واطئة، والتكتين يسمعون نفس الشي. إذا السماعة بقت بوضع الموسيقى (A2DP)، يبقى الصوت ستيريو واضح، ونكدر نرسل لكل تكة صوت مختلف.

## التشغيل

1. افتح الرابط بـ Chrome على التلفون.
2. افتح **الإعدادات** وحط مفتاحين:
   - **ElevenLabs:** سوّي حساب على elevenlabs.io، وبعدها روح لـ Developers ← API Keys.
   - **Claude:** سوّي حساب على platform.claude.com، واشحن رصيد، وبعدها روح لـ API Keys.
3. اضغط **جرّب التكات**: لازم تسمع صفارة باليسرى وبعدها باليمنى.
4. حط L بإذنك و R بإذن الشخص المقابل، وخلّي التلفون بينكم، واضغط **ابدأ**.
5. احجي جملة واسكت لحظة. التطبيق يترجمها ويشغلها بالتكة الصحيحة.

إذا ظهر تنبيه إن المايك الحالي من السماعة، اختار مايك التلفون من الإعدادات ← المايك.

## الإعدادات المهمة

| الإعداد | شنو يسوي |
|---|---|
| نموذج الترجمة | Opus 5.5 هو الأدق. Sonnet 5.5 و Haiku 5.5 أسرع وأرخص |
| الحساسية | إذا ما يلقط صوتك نزّل الرقم، وإذا يلقط الضوضاء صعّده |
| السكوت اللي ينهي الجملة | المدة اللي تسكت بيها حتى يعتبر الجملة خلصت |
| كل الترجمات بالتكتين | حتى تجرب التطبيق لوحدك |
| جرّب بدون مايك | تكتب جملة وتسمع ترجمتها، حتى تفحص المفاتيح والأصوات |

## حدود هذا النموذج الأولي

- **التأخير:** تقريباً 2 إلى 4 ثواني بعد نهاية كل جملة، لأن الترجمة تمر بثلاث خدمات على الإنترنت.
- **الكردي أضعف لغة:** التعرف على الكلام الكردي والصوت الكردي أقل دقة من العربي والتركي والإنكليزي. إذا ما اشتغل الصوت الكردي، الترجمة تبقى مكتوبة على الشاشة.
- **يحتاج إنترنت** ورصيد بالخدمتين.
- **لازم تبقى الصفحة مفتوحة.** التطبيق يحاول يخلي الشاشة شغالة طول ما هو يسمع.
- **المفاتيح محفوظة بس بالتلفون** (localStorage)، والمتصفح يرسلها مباشرة لـ ElevenLabs و Anthropic. لا تستخدم التطبيق على تلفون مو مالتك.
