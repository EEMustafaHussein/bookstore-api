# ترجمان: مترجم صوتي بالسماعات (مجاني)

نموذج أولي يشتغل من متصفح Chrome على تلفون Android. يحتاج **مفتاح واحد مجاني** من Google، بدون بطاقة ولا دفع.

- **التكة اليسرى (L) بإذنك:** تسمع ترجمة كلام الشخص المقابل بالعربي.
- **التكة اليمنى (R) بإذن الشخص المقابل:** يسمع ترجمة كلامك بلغته (كردي سوراني أو تركي أو إنكليزي).
- **كشف اللغة تلقائي:** إذا حجيت عربي يترجم للشخص المقابل، وإذا حجى هو يترجملك.

```
مايك التلفون ← كشف بداية ونهاية الجملة
            ← Gemini: يسمع + يعرف اللغة + يترجم (طلب واحد)
            ← Gemini: يحوّل الترجمة لصوت
            ← التكة اليسرى أو اليمنى حسب منو حجى
```

## المفتاح المجاني (مرة وحدة بس)

1. بالتطبيق افتح **الإعدادات** واضغط **افتح صفحة المفتاح المجاني** (aistudio.google.com/apikey).
2. سجّل دخول بحساب جيميل.
3. اضغط **Create API key**. إذا سألك عن مشروع (project)، اختار الموجود أو سوّي جديد.
4. انسخ المفتاح، ارجع للتطبيق، واضغط **الصق**. لازم يطلع «المفتاح شغال».

## التشغيل

1. اضغط **جرّب التكات**: صفارة باليسرى وبعدها باليمنى.
2. جرّب **جرّب بدون مايك**: اكتب جملة واضغط ترجم وشغّل.
3. حط L بإذنك و R بإذن الشخص المقابل، وخلّي التلفون بينكم، واضغط **ابدأ**.
4. احجي جملة واسكت لحظة.

## شنو يعني «مجاني»

- الخدمة المجانية من Google إلها **حد يومي** لعدد الجمل، والحد يختلف حسب النموذج.
- التطبيق يستخدم أكثر من نموذج. إذا خلصت حصة نموذج، يجرب اللي بعده تلقائياً.
- إذا خلص صوت Google، يشتغل صوت التلفون نفسه. هذا مجاني وبدون حد، بس يطلع **بالتكتين** وما بيه **كردي**، فالترجمة الكردية تبقى مكتوبة على الشاشة.
- الحصة اليومية ترجع كل يوم.
- Google يكدر يستخدم كلام الخدمة المجانية لتحسين خدماته، فلا تترجم بيها أسرار.

## ليش مايك التلفون مو مايك السماعة؟

أول ما يشتغل مايك سماعة البلوتوث، السماعة تتحول لوضع المكالمة (HFP): صوت مونو وجودة واطئة، والتكتين يسمعون نفس الشي. بوضع الموسيقى (A2DP) الصوت ستيريو وواضح، ونكدر نرسل لكل تكة صوت مختلف.

## حدود هذا النموذج الأولي

- **التأخير:** تقريباً 2 إلى 4 ثواني بعد كل جملة.
- **الكردي** أقل دقة من باقي اللغات، وما تأكدت إن صوت Google يدعم الكردي.
- **يحتاج إنترنت**، ولازم تبقى الصفحة مفتوحة.
- **المفتاح محفوظ بس بالتلفون** (localStorage)، وينرسل مباشرة لـ Google.
